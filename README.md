## 登录：三组服务器参数先存好，卡密格式各家还不一样

| 协议 | 服务器地址 | 端口 | 加密 |
| --- | --- | --- | --- |
| IMAP | imap-mail.outlook.com | 993 | SSL |
| SMTP | smtp-mail.outlook.com | 587 | STARTTLS 或无 |
| POP | pop-mail.outlook.com | 995 | SSL |

这几组参数在几家卖家的详情页里一字不差，属于微软邮箱的通用配置，不是某家的私有设置。填进客户端能不能连上，取决于账号本身有没有开对应协议，以及下面那条 OAuth2。

卡密格式也得先看清。一家发的是 `邮箱|密码`，另一家发的是 `邮箱-----密码`，分隔符不同。拿到卡密先确认分隔符再拆，用固定分隔符写批量脚本，格式对不上就整批解析失败。

## OAuth2：决定这个号能不能进客户端的那一条

> 微软2024年9月份协议更新，包含OAuth2的账户才能使用软件登录（如“心蓝邮箱助手”），未包含OAuth2的账号只能使用网页登录。批量购买前请少量购买测试。

这段是卖家写在商品详情里的说明，不是微软官方公告。它和标题里的“开通 POP3/SMTP/IMAP”放在一起很容易被误读：端口开着，不等于能用 OAuth2 客户端登录。协议开通只是说 IMAP/POP 可用，第三方软件走的是 OAuth2 授权，账号不带令牌就登不进去，只能在网页版里收信。

所以看到“使用网页登录”和“开通 POP3/SMTP/IMAP”同时出现，先问清到底属于哪一种。需要客户端自动收件的场景，比如批量取验证码、接工单系统、接到自己的邮件处理脚本里，必须确认带 OAuth2 令牌。

## 下单前确认这几项

- **登录方式**：只支持网页登录，还是带 OAuth2、能用第三方客户端
- **卡密格式**：`|` 还是 `-----`，能不能对上你现有的处理流程
- **协议状态**：POP3、IMAP、SMTP 是否开通
- **换号政策**：登不上能不能换、多久内换。这一条几家页面都没写清，只能自己问
- **用途边界**：卖家条款写明邮箱“主要用于注册接收邮件”，禁止用于诈骗信息推广、违规信息推广及其他非法用途，发现即封号

## 几个常被问到的问题

**同一批号，为什么有的能进客户端、有的只能网页？**
差别在 OAuth2。带令牌的账号能走第三方软件登录，不带的只能在网页版里用。

**“7 天页面”是什么？**
卖家页面里提到，微软邮箱新规则下不管新注册还是解锁的号都没有 7 天页面了，不用再纠结有没有触发 7 天。这是卖家的说法，用来解释他们圈子里的行话，不是微软的公开规则。

**买了之后能改密码吗？**
卖家页面没有说明改密规则，下单前直接问。改不了密码的号，等于你只有使用权，没有控制权。

**几毛钱的号和一块多的号差在哪？**
通常差在独享程度、是否带令牌、是否带初始邮箱。具体到某个商品，以详情页写的为准，别按价格反推。
